Result Caveats

两个非单调结果的解释

本页专门解释当前表格中看起来反直觉的结果。核心原则是：不要把所有指标强行解释成 hard condition 一定更高；应该区分 verifier-level uncertainty、waveform-confirmed drift、数据分布和模型背景风险。

异常一：Pretrained USEF-TFGridNet Speaker Side

在 pretrained USEF-TFGridNet 上，normal/easy reference 的 Speaker Confirmed Drift (1s) 和 Any Confirmed Drift Case 反而略高于 similar-speaker hard condition。这里的 similar-speaker hard 指的是早期 similar-speaker v2 汇总口径，主要覆盖 v2 0 dB / -3 dB，并不是后续补充的 v3 0 / -3 / -5 dB 全量表。

版本说明：v2 是 same-gender + top-similar speaker mining 的第一版 hard similar-speaker 数据；v3 后续加入 utterance-level acoustic matching 与 -5 dB SIR。v3 的完整结果请以“实验与结果”页 speaker-side v2/v3 对齐表为准。本页异常一保留 v2 口径，是为了解释最早观察到的“normal/easy confirmed drift 反而略高”的现象。
解释 1：similar-speaker hard condition 主要增加 speaker verifier 的局部不确定性，而不一定增加 waveform-confirmed speaker drift。强 pretrained USEF-TFGridNet 在 waveform separation 层面较稳，因此 verifier mismatch 不一定转化为 Target-Interferer SI-SDR Gap < 0。
解释 2：normal/easy 不等于每条局部片段都简单。SI-SNRi 和 drift 会受到句长、重叠比例、静音、source energy、mixture baseline 难度等因素影响，因此 normal/easy 可以存在非零甚至略高的 confirmed drift 背景风险。
汇报边界：不能说 pretrained USEF 在 similar-speaker 下出现大量真实 speaker swap。更稳的说法是：similar-speaker 提高了 verifier-level attribution uncertainty，但强模型的 waveform-confirmed speaker drift 没有同步放大。

异常二：BSRNN TFMap Content Side（历史归档）

这一异常来自旧 similar-content v2 TTS：TFMap 的 normal/basic fixed-enroll 在若干 content drift 指标上高于旧 v2 TTS。由于 v2 TTS 已被判定存在 all-uppercase TTS 可读性问题，相关数值表已经移入垃圾归档，不再作为正式 content-side 结论。

新版口径：TFMap / Context / USEF 的 content-side 差异必须使用 quality-first similar-content v3 的全量推理和 local diagnostic 重新判断。正式汇报中不再引用旧 v2 的 SI-SNRi、drift rate 或 case 数字。
