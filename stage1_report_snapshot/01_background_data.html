Background & Data

研究背景、数据构造与指标体系

本页说明本阶段研究为什么不只看传统 SI-SNRi，以及 hard condition、local verifier、Confirmed Drift 和 global-cue reliability calibration 如何构成一条完整证据链。

研究背景

Target Speech Extraction 的目标是在混合语音中，根据给定 cue 提取目标说话人的语音。对于 audio-only cue，尤其是 USEF / TFMap / Context 这类 fine-grained cue，模型可以利用 reference 的局部时序、时频和上下文信息进行更精细的目标抽取，但这些局部证据同时也携带 phonetic content、局部能量、说话状态和声学相似性等非身份因素。

因此，本研究的核心并不是简单证明 fine-grained cue 会经常出错，而是分析它在 hard-tail、similar speaker、similar content 和 cue-conflict 条件下是否需要可靠性校准。global cue 在这里不被定义为另一个直接参与分离的 feature，而是被定义为跨时间更稳定的 identity prior / verifier，用于检测和约束 fine-grained cue 的局部漂移。

这种局部错误不一定显著拉低整句平均 SI-SNRi，尤其当错误只发生在短时间片段时，传统指标可能把它平均掉。因此，本阶段实验把传统分离指标和局部 attribution diagnostic 放在同一个分析框架里，为下一阶段的 global-verifier-guided local calibration 提供依据。

修正后的研究主线

层级研究命题当前证据下一步作用
Fine-grained cue作为 separation 主体，提供局部抽取能力，但局部证据不是天然可靠。controlled BSRNN 中 USEF / TFMap / Context 在 speaker-side 和 content-side drift 行为不同。保留其主体地位，不把方法退化成普通 global-only TSE。
Local diagnostic用 1s chunk verifier、Target-Interferer SI-SDR Gap 和 case-level drift 判断局部归因是否偏向 interferer。clean-source sanity、multi-verifier、full-set BSRNN / pretrained USEF diagnostic。定义 high-risk chunk / hard-tail case，作为后续训练或校准目标。
Global cue作为 identity prior / verifier，而不是简单拼接到 separator 的额外 cue。强 USEF 说明强模型可能已经隐式学到部分稳定机制；弱 BSRNN 和 TFMap / Context 暴露更多漂移。用于 risk-aware gate、hard-negative margin、chunk-level identity consistency。
Solution target不以超过强 USEF 的 full-set SI-SNRi 为唯一目标，而以降低 hard-tail drift、保持 normal 不退化为主要收益。low SI-SNRi tail 与 drift 高度对齐；high SI-SNRi drift 数量少但有解释价值。评估方法时同时看 SI-SNRi、Confirmed Drift、Any/Persistent Drift Case 和 ASR readable evidence。

预训练模型与训练数据来源

本报告把公开预训练模型当作强参照使用，因此需要先说明它们的训练来源。这里采用“现有论文 / README 可确认的信息”作为证据边界；如果公开 checkpoint 的完整训练日志没有给出，则不把推测写成确定结论。

模型现有文档可确认的训练数据是否发现 similar-speaker 强化训练证据对本报告的解释意义
Pretrained USEF-TFGridNetUSEF-TSE 论文在 LibriMix / Libri2Mix / Libri3Mix 上评估，并使用 Libri2Mix / Libri3Mix 的 100-hour training subsets；文中还说明训练阶段未使用 dynamic mixing 或额外 data augmentation，训练语音被截断到 4s。目前没有在论文文本或本地公开材料中发现“按 speaker embedding mining 的 hard similar-speaker augmentation”证据。论文确实报告了 same-gender / speaker confusion 场景，这说明模型在标准 LibriMix 同性别混合上接受过评估，但这不等价于我们 v2/v3 的 hard similar-speaker 训练强化。因此，USEF 在 similar-speaker 上强，比较稳妥的解释是：强 backbone + USEF 表示 + LibriMix 同性别训练/评估已经带来较强 speaker discrimination；不能直接归因于它见过我们构造的 hard similar-speaker 数据。
REAL-TSE TFMap+ContextWeSep REAL-TSE README 公开了 tfmap_context_100 和 tfmap_context_causal_100 checkpoint；Multi-Level Speaker Representation 论文说明模型基于 clean Libri2Mix-100，训练集约 251 speakers / 13900 utterances，validation/test 各 3000 utterances 且说话人不重叠。目前没有发现它使用我们 hard similar-speaker v2/v3 或 quality-first similar-content v3 的证据。TFMap+Context 是重要 cue-composition baseline；新版 v3 中已显示它比 single USEF 更能减少 content-conflict tail。
本地 BSRNN 18epoch训练数据为 normal/basic LibriMix-100 风格数据；当前 18epoch 不是完全收敛版本，后续正在继续训练 USEF / TFMap / Context。没有 hard similar-speaker 或 similar-content v3 训练强化。BSRNN 18epoch 更适合作为 controlled cue ablation，而不是强 SOTA baseline。它能放大 cue 差异，但弱 backbone failure 需要和强预训练模型区分解释。
当前最稳妥的汇报口径：Pretrained USEF-TFGridNet 的 similar-speaker 稳定性是一个真实观察，但不能说它“因为接受过我们的 similar-speaker 强化训练所以正常”。现有证据只支持它接受过标准 LibriMix 100h 训练，并在 same-gender / speaker-confusion 条件下被评估。

数据难度与质量校准

本研究中的 hard dataset 不是为了制造任意低质量音频，而是为了在可控、可复现的条件下增加 cue attribution 的歧义。数据质量校准主要回答两个问题：第一，构造出的干扰是否真的接近目标 cue；第二，构造过程是否引入了会污染结论的音频质量问题。

Similar Content Quality-First v3

新版 v3 仍然服务于原始 motivation：fine-grained enrollment cue 中携带的局部 content-like evidence，是否会把 separator 拉向 mixture 中说相似内容的干扰源。与旧版本不同，新版把数据质量作为第一约束：不再使用 all-uppercase 文本；不再直接信任生成结果；最终数据必须经过生成后筛选。

Similar Speaker v2 / v3

维度统计结果解释
v2 数据规模v2 包含 0 dB 和 -3 dB 两个 SIR 条件，每个条件 6000 target tasks。v2 是第一版 hard similar-speaker 全量数据，用于确认 same-gender + top-similar speaker mining 是否能提高 speaker-side mismatch。
v2 构造方式从 LibriSpeech / LibriMix 元数据出发，优先选择与 target speaker 同性别、speaker embedding 更接近的 interferer speaker，并复用同一批 speaker pair 生成 0 dB / -3 dB 两个条件。v2 的主要压力来自 speaker identity similarity；它已经比普通 LibriMix 更难，但没有显式约束 utterance-level 声学状态。
v3 数据规模v3 包含 SIR 0 / -3 / -5 dB 三个条件，每个条件 6000 target tasks；created = 6000，read_skip = 0。v3 在 v2 基础上增加 -5 dB，使 interferer 相对 target 更强，更适合观察 tail failure。
v3 说话人筛选same-gender required；top-rank = 2；rank counts: rank-1 = 5598，rank-2 = 402。绝大多数样本使用最相似候选说话人，同性别约束避免性别差异把任务变简单。
v3 speaker 相似度speaker similarity mean 0.657，median 0.663，p10 0.608，p90 0.701。这里的 0.66 是 speaker embedding cosine-like 分数，不是“只有 66% 相似”。在跨说话人的 clean LibriSpeech 条件下，same-gender top-neighbor 能达到 0.60-0.70 已经说明两者处在较近区域；但它仍不是极端同音色或同一说话人近邻，因此强 USEF 不被击穿是合理的。
v3 声学距离acoustic distance mean 0.073，median 0.065，p10 0.029，p90 0.126。v3 不只看 speaker embedding，也引入 duration、RMS、zero-crossing-rate 等轻量声学匹配，减少“speaker embedding 相似但这一句话声学状态差很远”的情况。
v3 相对 v2 的提升v2 主要是 speaker-level hard mining；v3 = speaker-level hard mining + utterance acoustic matching + -5 dB SIR。所以 v3 更像一个集中 stress test：它尽量让干扰说话人不仅“身份相似”，而且“当前语音片段的声学状态也接近”，同时在 -5 dB 中进一步提高干扰源能量。
配对覆盖v3 unique undirected speaker pairs = 36；max pair count = 300。36 个 pair 的意思是：6000 条样本集中复用了 36 组高相似 speaker pair。这样做的好处是压力集中、便于稳定比较模型差异；局限是它不能代表真实世界中所有 possible speaker pairs 的分布。
SIR 控制v2: 0 / -3 dB；v3: 0 / -3 / -5 dB。可以区分“speaker 相似性”与“干扰声更强”两类压力。-5 dB 更适合观察 tail failure，0 dB 更适合和 normal/easy 对齐。
SIR 缩放方式SIR = 10 log10(P_target / P_interferer)。0 dB 表示两路功率相同；-3 dB 表示 interferer 功率约为 target 的 2 倍；-5 dB 表示 interferer 功率约为 target 的 3.16 倍。三版数据的说话人 pair 和文本结构保持一致，主要改变干扰源相对 target 的能量强度。
enrollment 可靠性enrollment_fallback_self = 0。没有使用当前 target 自身作为 enrollment 的 fallback，避免 enrollment 泄漏让任务变简单。

难度判断：Similar Speaker v3 比 v2 更严格：它同时约束同性别、speaker embedding 相似、utterance-level 声学距离和 SIR，并且避免 self-enrollment fallback。传统指标显示，强预训练 USEF 在 v3 上仍能保持较高输出质量，这说明强模型对当前 speaker-side stress 很稳；但对 BSRNN 18epoch / TFMap / Context 来说，v3 明显放大了 tail failure 与 speaker drift。

“36 个 pair 的 stress test”是什么意思：这不是说数据量只有 36 条，而是说 6000 条 utterance-level tasks 来自 36 组高相似 speaker pair 的重复采样。它适合回答“当说话人确实被挑得很相似时，模型是否更容易局部 drift”；但不适合回答“真实世界所有说话人组合上的平均风险是多少”。因此汇报时应把它称为 targeted stress test，而不是 population-level benchmark。

指标体系

指标计算方式回答的问题汇报用途
SI-SNRiSI-SNR(output,target_clean) - SI-SNR(mixture,target_clean)。整条语音相对 mixture baseline 的分离改善是多少？传统全局 improvement 指标，必须保留。
Output SI-SNR / SI-SDR直接计算 SI-SNR(output,target_clean) 或 SI-SDR(output,target_clean)，不减 mixture baseline。模型输出本身离 target 有多近？用于补充 SI-SNRi。hard mixture 本身更差时，SI-SNRi 可能偏高，因此需要同时报告绝对质量。
Mixture SI-SNR / SI-SDR Baseline计算 SI-SNR(mixture,target_clean) 或 SI-SDR(mixture,target_clean)。这个样本本身有多难？解释为什么 hard condition 中 SI-SNRi 可能更高：baseline 更差会抬高 improvement。
SDR / SIR / SARBSS Eval 系列指标。SDR 衡量整体失真，SIR 更关注干扰抑制，SAR 更关注伪影。输出质量下降主要来自残留干扰还是伪影？可作为传统分离指标补充，但对 permutation / target attribution 的解释仍有限。
PESQ / STOI / ESTOIPESQ 近似语音质量，STOI / ESTOI 近似可懂度。人耳可感知质量和 intelligibility 是否改善？适合作为导师汇报中的补充指标，尤其在 SI-SNRi 差异不明显时提供另一种视角。
ASR WER / CER对 output 跑 ASR，与 target transcript 比较 WER / CER。内容是否被听懂、是否说错词？对 similar-content 和 case study 很有价值；但 synthetic / target-like text 条件下要结合 speaker 与 waveform evidence 解释。
Speaker Similarity用 ECAPA / x-vector 等 speaker embedding 计算 output 到 target / interferer prototype 的 cosine similarity。输出说话人更像 target 还是 interferer？适合 speaker-side sanity 和 local diagnostic，但不能单独替代 waveform 指标。
Target-Interferer SI-SDR GapSI-SDR(output,target_clean) - SI-SDR(output,interferer_clean)，可在 utterance 或 1s chunk 上计算。输出从波形角度更接近 target 还是 interferer？作为 local mismatch 的 waveform confirmation。
Mismatch (1s)1s chunk 中 verifier gap < 0。speaker-side 用 speaker embedding，content-side 用 SSL content representation。局部 verifier 是否更偏向 interferer？局部风险信号。
Confirmed Drift (1s)Mismatch 且 Target-Interferer SI-SDR Gap < 0。verifier 和 waveform 是否同时认为 output 更接近 interferer？本报告最重要的局部强证据。
Any Confirmed Drift Case一条 utterance 至少有一个 Confirmed Drift chunk。多少样本被局部 drift 影响过？比平均 chunk rate 更适合汇报后果。
Persistent Confirmed Drift Case一条 utterance 中 Confirmed Drift chunk rate > 0.2。多少样本出现持续性 drift？强调较严重、非偶发风险。
本研究建议把传统指标分成三类同时汇报：第一类是 improvement，例如 SI-SNRi / SDRi；第二类是绝对输出质量，例如 Output SI-SNR / SI-SDR、PESQ、STOI；第三类是 attribution reliability，例如 Target-Interferer SI-SDR Gap、Mismatch 和 Confirmed Drift。这样可以避免 hard dataset 中 “mixture baseline 更差导致 SI-SNRi 看起来更高” 的解释歧义。

Clean-Source Verifier Sanity

在分析模型输出前，需要证明 verifier 对 clean target / interferer 本身是可分的。这里的 sanity test 不评价 TSE 模型，只评价 verifier 是否有资格作为局部诊断工具。

Sanity test计算方式关键结果结论
speaker verifier sanity对 clean target chunk 和 clean interferer chunk 计算其到 target / interferer speaker prototype 的 cosine gap；把来源是否为 target 作为二分类标签，扫阈值得到 ROC / AUC。1s AUC 0.9998，accuracy 0.9944；2s AUC 0.99999，accuracy 0.9977。即使 target/interferer speaker 相似，speaker verifier 在 clean source 上仍稳定。
content SSL sanity对 aligned clean target/interferer chunk 提取 SSL representation，比较 clean chunk 到 target / interferer clean reference 的 content gap。1000 samples / 10985 chunks；target / interferer clean-source accuracy = 1.000 / 1.000。SSL content representation 在 clean source 上没有 collapse，可用于 content mismatch 诊断。
