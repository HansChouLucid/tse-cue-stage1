阶段性汇报

Fine-grained Cue TSE 的局部可靠性分析

本报告基于 audio-only TSE cue 的阶段性实验，重点回答：fine-grained cue 在提供强局部抽取能力的同时，是否需要 global identity cue 作为稳定锚点，对 hard-tail 和 cue-conflict chunk 进行可靠性校准。

核心问题

传统 TSE 评价主要依赖 SI-SNRi / SI-SDRi 等整句平均指标，它能回答模型整体分离质量，但不能告诉我们模型在局部时间片段上是否把输出归因到了错误对象。对于 USEF / TFMap / Context 这类 fine-grained cue，局部归因是否稳定本身就是一个值得单独诊断和校准的问题。

修正后的主张：本研究不是要证明 fine-grained cue 经常大面积崩溃，而是证明 fine-grained cue 的局部证据不是 self-certifying 的。global cue 的价值不在于替代 fine-grained cue 做分离，而在于作为跨时间稳定的 identity prior / verifier，对 high-risk chunk 进行 reliability calibration。

主要结论

问题阶段性答案关键证据
local mismatch 是否真实可测？可以。clean-source verifier sanity 证明 speaker/content verifier 在 clean source 上可稳定区分 target 与 interferer。Speaker verifier 1s AUC 0.9998、accuracy 0.9944；content SSL clean-source accuracy 为 1.000 / 1.000。
强预训练模型是否也有局部风险？有，但主要表现为 content-conflict failure tail，而不是高 SI-SNRi 区间的大量持续 drift。quality-first v3 中 Pretrained USEF 的 Low SI-SNRi + High Drift 为 633 / 5256，Persistent Drift Case 为 12.27%。
TFMap+Context 是否只是弱 cue？不是。新版 v3 反而显示 TFMap+Context 是当前最强 content-side 参照。Pretrained TFMap+Context 的 SI-SNRi mean 为 15.27 dB，高于 USEF 的 12.24 dB；Low SI-SNRi + High Drift 为 217 / 5256，低于 USEF 的 633 / 5256。
controlled BSRNN 18epoch 是否足够？还不够。18epoch BSRNN 仍是偏弱 backbone，不能作为最终 cue 上限判断。旧 similar-content quick screening 数字已撤下；BSRNN 训练继续推进，后续用 selected checkpoints 在 quality-first v3 上重新评估。
SI-SNRi 能否单独解释问题？不能。SI-SNRi 与 drift 强相关但不等价。新版 v3 显示 content drift 主要集中在 Low SI-SNRi + High Drift tail；TFMap+Context 明显减少该 tail。
mismatch 后果是否被 chunk 平均率低估？是。chunk-level rate 衡量时间密度，case-level rate 更能体现有多少 utterance 被影响。近说话人 Context 的 speaker-driven confirmed case-level rate 为 0.2323。
