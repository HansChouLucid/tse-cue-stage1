Conclusion

阶段性结论与下一步计划

本页把当前证据收束成导师汇报口径，并列出后续需要补强的实验与 solution 方向。

可汇报结论

  1. fine-grained cue TSE 的 hard-condition behavior 不能只用平均 SI-SNRi 描述，需要同时报告 global performance 和 local attribution diagnostic。
  2. pretrained USEF-TFGridNet 是强模型参照，normal/easy SI-SNRi 很高，当前 hard set 下 confirmed drift 较低；它说明 fine-grained cue 可以非常强，但也要求我们把研究问题修正为局部可靠性校准，而不是证明模型经常崩溃。
  3. controlled BSRNN 18epoch 中，USEF 在 speaker-side 和 content-side 均最稳，TFMap / Context 更容易出现 Confirmed Drift。
  4. hard similar-speaker v3 在 BSRNN 上形成了更清楚的 case-level speaker-side tail：-5 dB 条件下 TFMap / Context 的 Any Confirmed Drift Case 分别达到 0.271 / 0.277，而 USEF 仍约 0.080。
  5. similar-content v2 和旧 v3 的正式结论已撤下：旧 v2 存在 all-uppercase TTS 可读性问题，旧 v3 存在 conflict 构造和 TTS 可读性问题。
  6. quality-first similar-content v3 已完成：5256 条 final rows，Whisper large-v3 ASR pass rate 99.98%，五组模型全量推理和 content local diagnostic 均完成。
  7. REAL-TSE TFMap+Context 在新版 v3 上优于 single USEF：SI-SNRi mean 15.27 vs 12.24，Low SI-SNRi + High Drift 为 4.13% vs 12.04%。这成为后续解释 cue composition 为什么能过滤 content conflict 的核心现象。
  8. TFMap+Context 的 similar-speaker 全局推理和 speaker-side local diagnostic 已完成：v3 0 / -3 / -5 dB 的 SI-SNRi mean 分别为 14.33 / 16.04 / 17.07，Speaker Confirmed Drift (1s) 稳定在约 0.045-0.046。
  9. BSRNN 在新版 v3 上仍是 weak-backbone 状态，三种 cue 的 SI-SNRi mean 为 -0.21 / -1.31 / -1.97，Persistent Drift Case 为 40.0% / 42.3% / 43.3%，因此需要继续训练后再做最终 cue ablation。

不能过度说的点

不应这样说原因建议表述
normal/easy 没有 drift。BSRNN fixed-enroll baseline 与 pretrained USEF-TFGridNet normal/easy baseline 都有非零 drift。普通条件存在背景风险，hard condition 与 cue mechanism 会改变或放大风险。
Context 整体最差。在当前 BSRNN v3 上 Context tail 最重，但 BSRNN backbone 仍偏弱，不能把它直接外推为所有 backbone 下的 cue 上限。更稳的说法是：在当前 BSRNN weak-backbone setting 中，Context 对 content conflict 最敏感。
local mismatch 与 SI-SNRi 完全独立。低 SI-SNRi tail 与 drift 高度对齐。二者强相关但不等价；local mismatch 解释和定位 tail failure。
SepFormer 可以直接进入 local mismatch 横向对比。SepFormer normal/easy SI-SNRi 已经为负，local drift 会被普通分离失败污染。当前只能写成 compatibility failure。
mismatch 证明模型经常大面积崩溃。chunk-level rate 并不支持这种表述。更准确地说：mismatch 是可定位、可分型、和 cue mechanism 有关的局部风险。

Hard Similar-Speaker Stress Test

Hard similar-speaker v2/v3 已完成构造、pretrained USEF-TFGridNet 全量推理和 speaker-side local diagnostic。v2 主要提高 speaker-level similarity；v3 在 v2 的基础上加入 utterance-level acoustic matching，并额外加入 target -5 dB 条件。诊断口径与 v1 speaker-side 完全对齐，因此可以直接和 normal/easy reference 比较。

阶段结论：v3 比 v2 更能提高 Any Mismatch Case，说明 utterance-level acoustic matching 确实让局部 speaker attribution 边界更紧；但严格的 waveform-confirmed drift 没有明显升高，甚至随 target SIR 降低略降。这说明强 pretrained USEF-TFGridNet 在 speaker-side 仍然很稳，当前 v2/v3 更像是提高了 verifier disagreement，而不是造成大规模 target/interferer drift。
传统指标也支持这个解释：-3 / -5 dB 条件下 SI-SNRi 更高，不代表输出绝对质量更好，而是因为 Mixture SI-SNR baseline 更低。v3 -5 dB 的 SI-SNRi mean 为 19.10，但 Output SI-SNR mean 为 14.00，低于 0 dB 条件的 15.83。因此后续报告 similar-speaker hard set 时，应同时展示 SI-SNRi、Output SI-SNR 和 Mixture SI-SNR baseline。
下一步如果继续 speaker-side，应从“全局说话人相似”转向“局部冲突”：短 enrollment / low-coverage enrollment、target sparse 或 absent chunk、局部 interferer dominance，以及 speaker identity 与 fine-grained cue 明确冲突的样本。否则继续堆 similar speaker 版本，边际收益可能不大。

Solution 方向

方向核心想法评估指标
mismatch-aware detector融合 speaker/content gap、Target-Interferer SI-SDR Gap 和 SI-SNRi tail，输出 chunk-level / case-level risk score。Confirmed Drift detection recall / precision，高风险 case 排名质量。
cue reliability gate当 fine-grained cue 局部不可靠时，降低其对 separator 的影响。降低 high-SI-SNRi-with-drift cases，同时保持 SI-SNRi。
verifier-guided local constraint在高风险 chunk 上加入 speaker/content 一致性约束。降低 Confirmed Drift (1s) 和 Persistent Confirmed Drift Case。
hard negative curriculum把 similar-speaker / quality-first v3 等 hard negative 加入训练或重加权。speaker-side 和 content-side case-level drift 同时下降。
