Mechanism Probe

从 cue 内部歧义到最终输出漂移

本页把 local mismatch 的研究从 waveform 输出层进一步推进到 cue 机制层：fine-grained cue 是否在与 mixture 交互之后产生局部 target / interferer ambiguity；这种 ambiguity 又有多少真正转化为 output-level confirmed drift。

问题定义

当前证据显示，强模型在 SI-SNRi / SI-SDRi 上可以保持较好表现，但这并不意味着 cue 内部完全没有局部歧义。机制 probe 的目标不是替代最终分离指标，而是回答更细的问题：cue 在局部到底是在稳定支持 target，还是在 target 与 interferer 之间摇摆。

层级检测问题当前解释
cue-level ambiguitycross-attention / TFMap / conditioned cue 表示是否在局部更接近 interferer，或 target preference 很弱。这是机制层风险，可能被 separator 吸收，也可能转化为输出漂移。
output-level confirmed drift最终 waveform chunk 是否被 speaker/content verifier 和 waveform gap 同时判定为偏向 interferer。这是更严格的输出错误证据，但会低估被模型吸收的内部歧义。
核心表述：强 USEF 不出现大面积 waveform drift，并不直接否定 fine-grained cue 的 mismatch hypothesis。更合理的主线是：cue 层 ambiguity 可能普遍存在，但强 separator 会吸收大部分 ambiguity；研究价值在于识别哪些 ambiguity 会变成 hard-tail output drift。

指标口径

指标计算方式解释
target-interferer margin对同一局部 cue 表示，计算其与 target reference 表示的相似度减去与 interferer reference 表示的相似度。margin > 0 表示更偏 target；margin < 0 表示更偏 interferer；接近 0 表示 target preference 弱。
Negative-margin frame rate局部 frame / chunk 中 margin < 0 的比例。严格的 cue 错指比例。
Weak Preference Rate局部满足 |margin| < 0.05 的比例。target / interferer 区分不清的比例。
Ambiguous Cue Mass局部满足 margin < 0.05 的比例。把“明确偏 interferer”和“target preference 不够强”合并为 cue 风险面积。
Attention entropy / peak对 attention 权重计算归一化熵和最大权重。高熵低 peak 更像注意力分散；低熵但 margin 低则更像尖锐但指向不稳。
Persistent ambiguity统计连续 weak / negative margin 片段的最长持续时间，以及是否超过 0.5s、1s、2s。区分随机抖动和持续风险片段。
口径确认：这里比较的是 cue 与 mixture 交互之后的表示，而不是 enrollment-only 表示。TFMap 使用 mixture magnitude 与 enrollment magnitude attention 后的 target-related T-F map；USEF 使用 mixture encoded feature 与 enrollment encoded feature cross-attention 后的 conditioned feature。

Ambiguity 是否转化为 Output Drift

为避免过度解释黑盒模型，本报告采用更谨慎的术语：如果 cue margin 弱或为负，但同一 chunk 最终没有 waveform-confirmed drift，称为 absorbed ambiguity；如果同一 chunk 出现 confirmed drift，称为 converted drift。这是一种统计关联，不等同于直接证明 separator 内部进行了因果纠错。

模型 / cue粒度与覆盖关联结果结论边界
BSRNN 18epoch / TFMap1s chunk；6000 utterances / 42335 aligned chunks。AUC 0.585，AP 0.105；negative cue chunk confirmed drift rate 0.107，高于 strong-target cue 的 0.054；negative cue absorbed approx 0.893。低 margin 与 drift 有正相关，但不是强决定因素；shuffle control AUC mean 为 0.586，提示时间对齐优势较弱。
BSRNN 18epoch / USEFutterance-level；300 utterances。Any drift AUC 0.575；Persistent drift AUC 0.552。只能说明 utterance 平均 margin 与 case-level drift 弱相关；需要导出 chunk margin 序列做强分析。
Pretrained USEF-TFGridNet / USEFutterance-level；1000 utterances。Any drift AUC 0.557；Persistent drift AUC 0.538。强模型 output drift 低，支持“大量 ambiguity 被吸收”的现象描述，但还不能解释内部机制。

当前结论与后续补强

已能支持还不能直接支持下一步需要补什么
speaker-side hard set 上，TFMap 与 USEF 都存在不小的 cue-level ambiguity。不能直接说所有 ambiguity 都会导致 audible mismatch。做 absorbed vs converted 的 matched-case 分析。
强 USEF-TFGridNet 输出层稳定，但内部 margin 仍接近 0。不能直接说 separator 的具体哪一层纠正了 ambiguity。做 cue perturbation、high-ambiguity chunk masking 或 global reliability gate 的反事实实验。
TFMap margin 与 output drift 有弱到中等的 dose-response。不能只靠 margin 单指标解释 drift。加入 local SIR、overlap、activity、energy 和 verifier gap 的分层 / 匹配 / risk model。
机制 probe 目前主要覆盖 speaker side。不能把 speaker-side 结论直接外推到 content side。基于 quality-first similar-content v3 补 content-side cue mechanism probe，重点比较 Pretrained USEF 与 Pretrained TFMap+Context。
