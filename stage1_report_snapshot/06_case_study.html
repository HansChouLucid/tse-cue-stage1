Case Study

SI-SNRi 与 local drift 的样本级分析

本页只保留当前可作为正式证据的 case-study 结果。旧 similar-content v2 与旧 similar-content v3 已移入垃圾归档；content-side 已替换为 quality-first similar-content v3 的全量分桶。

Case 分类规则

类别筛选规则研究意义
High SI-SNRi + DriftSI-SNRi >= 10 dB 且 confirmed drift rate > 0；强版本使用 confirmed drift rate >= 0.2。检验传统全局指标是否掩盖局部 attribution risk。
Low SI-SNRi + High DriftSI-SNRi < 0 dB 且 confirmed drift rate >= 0.2。解释 failure tail：失败是普通分离差，还是 target/interferer attribution drift。
Stable Success ControlSI-SNRi 高，confirmed drift 为 0。作为高质量且局部稳定的正对照。
Ordinary Failure ControlSI-SNRi < 0 dB，但 confirmed drift 为 0。区分普通分离失败与 drift-driven failure。
content-side 的 confirmed drift 使用 2-verifier content mismatch 与 waveform direction 同时支持偏向 interferer 的 1s chunk；case-level Persistent Drift 定义为 utterance 中 confirmed drift rate >= 0.2。

Content-side Quality-first v3

quality-first v3 的 final rows 为 5256。该数据保持自然 Libri2Mix mixture，只替换 enrollment：用 target speaker voice 说出 interferer transcript，从而制造 cue-content-to-interferer conflict。Whisper large-v3 质量验证显示 WER mean 0.033、CER mean 0.015、token F1 mean 0.971，ASR pass rate 99.98%。

最清楚的结论是：High SI-SNRi + High Drift 几乎不存在，说明持续 content drift 一旦发生，通常会显著伤害整句重构质量；Low SI-SNRi + High Drift 是 content-side 的主线。Pretrained TFMap+Context 把 Low SI-SNRi + High Drift 从 USEF 的 12.04% 降到 4.13%，这是目前最有价值的新现象。
BSRNN 三 cue 的 Low SI-SNRi + High Drift 均超过 37%，说明当前 BSRNN 在 v3 上仍是 weak-backbone failure。它可以用来观察 content conflict 如何被放大，但不能直接用来判断 USEF / TFMap / Context 的最终上限。

Speaker-side Similar-speaker Case Study

speaker-side 不受 similar-content TTS 质量问题影响，因此保留为正式证据。这里关注 similar-speaker 条件下模型是否在局部片段中偏向干扰说话人身份。

模型当前可用数据全量规模可支持的分析边界
Pretrained USEF-TFGridNetcondition-aware utterance taxonomy 中的 similar-speaker 行6000可做 SI-SNRi 与 speaker drift 的逐样本交叉分类。强模型的 high-SI-SNRi confirmed drift 很少，主要用于分析低 SI-SNRi tail。
Controlled BSRNN 18epochsimilar-speaker multiverifier per-utterance summary + full SI-SNRi log每个 cue 12000可比较 USEF / TFMap / Context 三种 cue 的 speaker drift tail。BSRNN 18epoch backbone 偏弱，后续需用继续训练后的 checkpoint 复核。

归档与回填规则

规则说明
旧 content 指标不再引用任何带旧 similar-content v2、旧 v3、SCV2TTS、20260607 old v3 的 case study 或 metric 表，都只允许出现在垃圾归档中。
新版 v3 已回填当前已回填传统指标 SI-SDR / SI-SDRi / SI-SNR / SI-SNRi、local diagnostic 与 case bins；Pretrained USEF 的 SI-SDR 已按 8 kHz output 对齐重采样后补算。
case 表要去重代表样本优先按 speaker pair、text template 或 enrollment template 去重，避免把同一模板重复展示成多个独立模式。
