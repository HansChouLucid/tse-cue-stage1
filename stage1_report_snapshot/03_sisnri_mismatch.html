SI-SNRi × Confirmed Drift：从指标到机制

本页说明如何联合解释传统指标和 local mismatch。content-side 已使用 quality-first similar-content v3 重新填入分桶结果；旧 v2 / 旧 v3 数字不再引用。

为什么要联合看

SI-SNRi 是整句平均指标，它能回答模型整体分离质量，但无法定位局部 chunk 是否更像 target 还是 interferer。Confirmed Drift 要求 content/speaker verifier 和 Target-Interferer SI-SDR Gap 同时偏向 interferer，因此能提供局部 attribution 方向。

联合逻辑：SI-SNRi 回答“整体分离好不好”，Confirmed Drift 回答“局部有没有跟错对象”。二者合起来，可以把失败从单一的低分离质量拆成可解释的 failure types。

四象限框架

区域解释研究价值后续处理
高 SI-SNRi + 低 Confirmed Drift整体分离好，局部归因也稳定。stable success，作为正例参照。分析 cue 正常工作模式。
高 SI-SNRi + 有 Confirmed Drift整句平均质量不错，但局部 chunk 曾偏向 interferer。说明传统指标可能掩盖局部风险。整理 top-k case、timeline 和音频证据。
低 SI-SNRi + 高 Confirmed Drift失败样本中存在明确 attribution drift。解释低 SI-SNRi tail 的重要来源。用于 detector、hard negative 和 verifier-guided constraint。
低 SI-SNRi + 低 Confirmed Drift输出差，但没有可靠证据说明跟错 target/interferer。ordinary separation failure。通过 backbone、数据和传统 separation loss 改善。

新版 v3 的核心读法：content drift 不是高 SI-SNRi 区间的常见隐藏错误；一旦形成持续 drift，通常会显著拉低整句 SI-SNRi。因此 content-side 的主要研究对象是 Low SI-SNRi + High Drift tail，而不是“高质量输出里大量说错内容”。
最值得继续研究的是 Pretrained TFMap+Context 相比 Pretrained USEF-TFGridNet 显著减少 tail：Low SI-SNRi + High Drift 从 12.04% 降到 4.13%。这提示 cue composition 可能在过滤 enrollment-content conflict 上有优势。
