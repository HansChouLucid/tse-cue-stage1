关键指标注释

指标计算/含义如何解释
SI-SNRiest 相对 mixture 的 SI-SNR 改善。整体分离质量；不能单独说明是否抽对人。
speaker_gapsim(output chunk, target speaker prototype) - sim(output chunk, interferer prototype)。负值表示 speaker verifier 更偏 interferer。
speaker mismatch ratespeaker_gap < 0 的有效 chunk 比例。衡量 local speaker identity drift。
local SI-SDR gapSI-SDR(output, target chunk) - SI-SDR(output, interferer chunk)。负值表示 waveform 层面更接近 interferer。
content_gapsim(output, target content) - sim(output, interferer content)，使用 wav2vec2-base 中间层。负值表示 content embedding 更接近 interferer reference。
content mismatch ratecontent_gap < 0 的 chunk 比例。衡量局部 content attribution drift。
joint content+waveform ratecontent mismatch 且 waveform 更接近 interferer 的 chunk 比例。比 content-only 更强的 content drift 证据。
WER / token F1ASR 输出与 target transcript 的词错误率和 token overlap。用于 readable evidence；v2 中不能单独区分 target/interferer attribution。
