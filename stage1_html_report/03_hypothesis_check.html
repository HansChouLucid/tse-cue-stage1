与原始假设存在张力或冲突的地方

冲突 / 张力实验观察含义
hard condition 不一定降低平均 SI-SNRipretrained USEF 在 similar-speaker 和 v1 上平均 SI-SNRi 与 normal/easy 接近。第一阶段论点不能写成“平均性能显著下降”，而应写成 tail/local mismatch。
v2 TTS 的 speaker-side mismatch 没有爆发v2 speaker mismatch 低于 similar-speaker。v2 的核心不是 speaker identity collapse，而是 content attribution stress。
ASR 不能单独证明 target/interferer attributionv2 synthetic interferer 使用 target text。ASR 是 readable evidence，不是 attribution oracle；核心仍是 SSL content + waveform。
BSRNN baseline 较弱train-100 / 5 epoch BSRNN SI-SNRi 明显低于 pretrained USEF。BSRNN 适合作 cue mechanism comparison，不适合作最终强性能比较。
USEF speaker-side 指标并非全方位最优BSRNN v2 中 USEF speaker_mismatch_mean 不低。USEF 的优势主要体现在更少进入 content collapse 和更高整体稳定性，而不是每个局部 speaker 指标都最好。

当前可写成论文式表述的结论

1. Fine-grained cue TSE 的 hard-condition failure 具有局部性和条件依赖性。
2. Similar-speaker 主要暴露 speaker identity mismatch；similar-content v2 TTS 主要暴露 content attribution mismatch。
3. 强 pretrained USEF 也存在 tail/local mismatch，因此问题不是弱 baseline artifact。
4. Controlled BSRNN 说明 cue mechanism 会系统性影响 mismatch，USEF 比 TFMap/Context 更稳定。
5. v2 TTS 的 content mismatch 可由 SSL content gap 量化，并可由 ASR/token-level evidence 佐证输出文本崩坏或恢复。
