Toolkit 原始研究主线

原始 toolkit 的核心不是简单比较“哪种 cue 平均 SI-SDR 更高”，而是重新划分 cue 的角色：

角色原始设想原因
Fine-grained cue作为 separation 主体保留 reference 的局部发音、谱结构、上下文和 target-related local evidence。
Global cue / SV embedding作为 independent verifier提供稳定 speaker identity anchor，用于检测 fine-grained cue 的局部错配。
Mismatch controller第二阶段 solution 模块当 verifier / matching / activity 信号显示局部风险时，进行局部约束或修复。
核心转向：从“更多 cue 是否提升平均指标”转向“fine-grained cue 在什么条件下会局部失效，以及 global verifier 如何检测和缓解”。

原始核心假设

假设内容当前状态
H1 Fine-grained 主体优势fine-grained cue 保留局部状态和上下文，适合作 separation 主体。部分支持，但当前 controlled BSRNN 是弱 baseline，尚未完整证明其优于 global cue。
H2 Local mismatch 风险similar speaker/content 条件下，fine-grained cue 可能被局部相似性误导。强支持，已有 speaker-side 和 content-side mismatch 证据。
H3 Global verifier 有效预训练 SV embedding 或 prototype 适合作独立 verifier。部分支持，ECAPA/SpeechBrain 已能解释 speaker mismatch；后续还需 verifier-guided solution。
H4 TSE-joint embedding 可能退化联合训练 embedding 可能失去 speaker verification 判别性。尚未覆盖，需要后续对照实验。

第一阶段与第二阶段的分工

阶段目标当前进展
第一阶段：failure-mode analysis证明 local mismatch 存在、触发条件、可检测性。基本完成。
第二阶段：global verifier-guided solution用 global verifier 检测、约束或修复 fine-grained cue mismatch。尚未开始，是下一阶段主线。
